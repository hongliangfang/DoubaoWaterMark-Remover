## 功能特性

### 🎛️ 就绪提示

- ✅ 进入豆包页后，**右下角**自动出现**页内蓝色面板**，顶栏显示「加载成功」说明插件正常加载即可使用

### 🖼️ 无水印图片

- ✨ **对话页无水印原图生成**：豆包对话页面新生成的图片直接展示的是无水印图片
- ⬇️ **豆包图片原生下载**：可直接利用豆包图片上的原始下载按钮进行下载
- 🖼️ **会话内图片 + 右侧大图**：豆包会话窗口内的图片与预览链路均进行了无水印处理直接可查看
- 📥 **会话窗口图片一键下载**：可直接利用页面内蓝色面板将会话窗口内生成的图片一键下载，节省时间


### 🎬 无水印高清视频

- 🚀 **高清原始无水印视频**：通过对豆包接口进行解密处理后可支持高清原始视频下载
- ℹ️ **会话内不处理需下载后查看**：不对会话里的视频播放与预览画面做无水印处理；通过面板 **下载后查看**，获得的即为豆包无水印高清视频

### 📋 媒体管理（页内面板）

- 🎛️ **页内蓝色面板**：打开豆包会话即可出现，可获取当前会话的所有资源，并且可按需选择获取图片或者视频
- 🗂️ **插件看板资源库**：可打开插件按钮查看完整案板，支持打开后的所有会话资源处理并按「会话标题 - Chat ID」进行管理，方便区分
- ✅ 勾选批量下载；支持图片 + 视频一键或者批量下载
- ✅ 页内面板每张媒体左侧都有勾选框，可只提交选中的图片或视频
- ✅ 下载设置支持高清原图、标准高清和节省空间三档；低画质图片先从无水印原图本地压缩，视频按无水印候选清晰度选择

### 📚 历史对话素材

- 打开或刷新过的会话，图片与视频会进入本机历史
- 支持按会话筛选后批量下载高质量无水印图片 / 视频
- 说明：不会在后台扫描账号里「从未打开过」的全部对话；重新打开旧会话后即可捕获

## 特别说明

### 会话范围

1. 当前打开的会话  
2. 安装后新建并打开的会话  
3. 安装前的旧会话——重新打开或刷新后再捕获  

「全部会话」= 插件本机已捕获的会话，不是豆包服务器全量历史。

### 视频原理（简要）

在页面内拦截豆包会话链路响应中的 `fallback_api`，再本地解析无水印视频地址并下载。

## 使用方法

### 图片

1. 打开含生成图片的豆包会话并刷新  
2. 确认会话内图、右侧大图为无水印；可用页内面板下载  
3. 豆包原生下载按钮也应尽量得到无水印原图  

### 视频

1. 打开含生成视频的会话并强制刷新  
2. 会话页内面板显示「已就绪」或「加载成功」  
3. 使用预览 / 下载；下载来源一般为字节相关视频域名  

### 历史与批量

1. 在多个会话中捕获媒体后打开可进行历史图片和视频管理 
2. 按会话与类型筛选，勾选后批量下载  
3. 需要时调整缓存上限并「立即整理」  

### 下载位置与手动控制

- 媒体会自动捕获并进入页内面板 / Popup，但不会自动下载；是否下载、下载哪些条目由你逐项点击或勾选后操作。
- Popup 的「下载设置」可以填写保存子目录，例如 `Doubao/我的项目`。Chrome/Edge 的下载 API 只接受相对于浏览器默认“下载”目录的路径，因此这个字段可设置多级子目录，图片和视频共用该设置。
- 勾选「每次下载前询问保存位置」后，Chrome/Edge 会对每个下载任务弹出保存位置选择器；批量任务会串行询问，所以一次“全部下载”看到多个逐项选项是浏览器的预期行为。关闭它即可自动保存到设置的子目录。
- 页内蓝色媒体面板右上角齿轮按钮还提供「选择文件夹」。在支持 File System Access 的 Chrome/Edge 中，你可以一次选择基础文件夹，再设置子目录；页内面板会直接把单项或批量任务写入该文件夹，刷新页面后会尝试恢复本地保存的文件夹权限。
- 如果浏览器不支持文件夹权限、权限被撤回，或跨域媒体不能由页面直接读取，页内面板会自动回退到浏览器下载队列。Popup 仍使用浏览器下载目录 / 相对子目录模式。
- 面板右下角的斜线拖拽柄可以调整宽度和高度，尺寸会保存在当前豆包站点的本地存储中，刷新页面后自动恢复。
- 图片下载优先使用接口返回的原图字段 `image_ori_raw`；视频下载会重新解析 `fallback_api` 并请求最高质量的无水印地址。

## 开发与反馈

- 不需要每次修改都下载 ZIP：把仓库克隆到本地固定目录后，后续执行 `git pull --ff-only`，再到 `chrome://extensions/` 点击扩展的「重新加载」即可。扩展源码目录是 `doubaoparser/`。
